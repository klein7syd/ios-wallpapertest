# Todo Wallpaper
原生iOS待办、壁纸、小组件与连心；iOS17+，无第三方库。
Windows用户解压安装包，连接iPhone，双击Install-TodoWallpaper.cmd；同账号覆盖安装，不先卸载。
密钥仅在本机钥匙串；只接HTTPS，照片不发AI，共享内容不带凭证、接口、提示词或角色资料。
连心角色仅名字、团体、称呼、500字补充；旧资料一次迁入补充，旧JSON仍可读。
一次生成1–8句（默认4），可逐条编辑/删除；体验模板不联网，复制分享保留创作后缀。
组件与壁纸按容量显示多句话语；壁纸至少一条完整可导出，单条截断仍禁止导出。
待办/连心的标记在整行（含日期/译文）居中，预览与正式渲染共用布局。
默认交付仅Windows安装包zip与15行内说明；不自动生成审阅/快照/Evidence或更新交接文档。
按需审阅：运行tools/export_review.sh，参数为基线提交与可选输出目录，内容直接来自git diff/git archive。
按用户新规移除Instruments/数字采样门禁、默认handoff调用及对应结构约束；其余门禁保留。
旧单句格式/独立角色核对等断言随新生成协议调整；仅新增旧角色迁移及新旧多句兼容两个断言。
本地编译优先；每任务完整CI一次、失败最多重试两次，不新增界面原生检查。
真机触摸、系统组件刷新、签名升级和真实AI效果需设备验证，编译不代表真机通过。
