# Todo Wallpaper
原生 iOS 待办、壁纸、小组件与连心；最低 iOS 17。
本轮 UI：待办增加全部/待完成/已完成筛选和数量摘要，保留原任务顺序。
筛选后的删除按ID处理；仅全部列表支持拖动排序，切换筛选退出编辑。
新增待办按事项、日期、标记、导入分区，键盘工具栏提供完成按钮。
壁纸/小组件工具放在参数区上方，当前内容来源明确显示，可选待办或连心。
壁纸参数区适当增高，小屏仍为画布留空间；右上角直接进入保存/分享。
小组件参数采用独立圆角卡片，明暗、背景、字体等选择器增加可见标题。
两页更多菜单均可直接开关高级调整；小组件预览重置也收进该菜单。
保留共享渲染、照片裁剪、精确导出、撤销和安全规则；受保护源码哈希不变。
未新增UI检查，未修改或放宽现有检查；编译结果见安装包说明。
Windows解压运行Install-TodoWallpaper.cmd，用原账号覆盖安装，不先卸载。
尚需真机确认：筛选/编辑/排序、深浅色、大字体、键盘及实际触控体验。
