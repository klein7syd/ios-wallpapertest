# Todo Wallpaper 0.4.0 · D3 + D4

包内是**未签名真机 IPA**、R1 Windows 多扩展安装脚本、真实日志及原生渲染样图。未签名 IPA 不能直接安装。此版本保留 App/Widget/App Group 安装身份；勿卸载 0.3.0 / 1005。

## Windows 覆盖安装

1. 完整解压 ZIP。USB 连接、解锁并信任原来的 iPhone。
2. iPASide 使用安装旧版时的同一 Apple Account，会话有效；暂时暂停普通自动刷新并关闭其窗口。
3. 双击 `Install-TodoWallpaper.cmd`，必要时指定 iPASide 安装目录。沿用 R1：分别签名 App 与 Widget、检查资源/代码完整性，再覆盖安装。不要用普通单 App 模式移除扩展。
4. 遇到错误保留旧 App，提供可见报错，勿上传凭据、证书、profile、设备标识或已签名包。
5. 关于页核对 0.4.0 和实际 Build。旧待办 UUID/顺序/完成状态以及背景照片、草稿不应消失。

## 真机验收

- **旧功能回归**：新增、编辑、删除、排序、完成/恢复。杀后台后再开，数据保留。已有小中大小组件继续直接操作；点击后不强制打开 App。
- **画布界面**：大预览、底部五组工具、收起/展开参数和全屏预览；原生底部导航仍正常。切换文字颜色快捷色、RGB/透明度和系统取色器，直接观察画布。系统色板的弹出形式由 iOS 管理，快捷色/RGB留在底部。
- **连续操作**：背景工具下直接拖动、双指缩放；其他工具下直接拖动面板，开启自定义位置，接近中心显示辅助线。连续滑动位置/透明度/模糊，观察有无等待、明显跳帧、闪烁。再测试精确输入和 1 输出像素的箭头微调。
- **字重**：同一段中英文依次选择细/常规/中等/半粗/粗体，对照全屏精确预览和保存 PNG。系统字体应明显不同；中文/特定衬线字库可用字重有限时合理降级，PingFang 粗体可映射半粗。
- **自由 Emoji**：标记工具选择自定义 Emoji，打开系统 Emoji 键盘输入快捷列表之外的图案，再试 ❤️、👍🏽、🧑🏽‍💻、👨‍👩‍👧‍👦、🇨🇳。不能出现拆分/方框/黑白化。粘贴多个 Emoji/普通文本/超长内容应提示且不覆盖上次有效标记。可清除标记和重新选择。
- **单项覆盖**：在待办编辑页关闭“继承全局默认”，分别给听歌/健身/学习设置 🎵/💪/📚。更改全局默认时这些单项仍保留。重新开启继承恢复全局；新待办自动继承。完成/取消完成、重启和覆盖安装后单项设置均保留。
- **标记外观**：空心/实心/细线/带边框圆、方框、Emoji、不显示；选择不显示时，待办列表仍可轻扫完成/恢复，空白标记区也保留点击区域；调整大小、线宽、填充/描边/完成颜色、间距/垂直偏移，检查长标题对齐。完成时选择保留/变淡/替换/图形加勾；Emoji 不应被强制变成圆圈。
- **比例与 4K**：新草稿默认 19.5:9、1890×4096；16:9 输出 2304×4096。旧草稿保持旧精确比例及旧输出，不会静默改成4K，需手动选择。仅改适中/4K时，面板相对位置、换行、裁剪、圆角和 Emoji 位置应保持。自定义画布如1:1可用适中2048²；自定义像素需匹配画布比例。不匹配/超限应提示，不能拉伸照片。
- **真实 PNG**：分别保存现代/经典4K，在照片信息核对像素尺寸，放大检查彩色Emoji、字重、裁剪与文字清晰度。全屏“精确预览”使用稳定后的原生位图。相册只在主动保存时新增图片；系统分享及拒绝相册权限仍正确处理。
- **Widget 样式**：从关于页或标记工具打开独立外观页，测试亮/暗/系统、背景、文字色、字体/字重、Emoji大小、密度、数量和完成显示。小号标记不应挤坏标题。点击“将壁纸样式应用到小组件”后等系统刷新，照片/画布位置不应复制，单项Emoji仍优先。再单独修改Widget样式，壁纸保持独立。
- **最后回归**：重启手机，检查待办/单项Emoji/全局和Widget样式/壁纸草稿。用同一脚本再次覆盖安装，确认仍保留，且小组件仍可直接完成和恢复。

## 边界

真实流畅度和上述交互要以手机反馈为准；CI只证明代码编译与合成图片/文件检查。系统Widget刷新有调度限制，系统着色可能改变背景和Emoji呈现。Widget无法任意透明或使用壁纸照片当共享透明底。

实时预览的GPU模糊和导出CoreImage可能有细微差别，共用坐标、裁剪、CoreText排版和标记规则，不承诺像素级相同。导出是静态SDR sRGB PNG，不支持后台自动更换系统壁纸、HDR或Live Photo。原图保留，解码工作长边最多6144；不足像素会提示，4K不能补出源图没有的细节。

每边480–4096、总像素最多1200万，因此4096²方形超限，请选适中或自定义。19.5:9为通用近似，实际机型可能微裁剪，使用安全边距。单项设置 > Widget默认(仅Widget) > 全局默认。旧二进制编辑数据可能丢弃未知新字段，请采用向前覆盖升级，不要降级回写。
