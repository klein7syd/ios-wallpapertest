# 0.5.1 / Build 1026 — iPhone 验收

IPA 未签名。使用原来 Windows iPASide 的同一 Apple Account 和已验证 R1 `Install-TodoWallpaper.cmd` 覆盖安装；不要卸载旧 App。不要只用会移除扩展的普通单应用签名方式。三个安装标识均保持。

1. 打开后检查原待办、顺序、完成状态、单项 Emoji、日期、壁纸草稿与照片保留；确认关于显示 0.5.1 / 1026。
2. 小组件 → 主题：关闭玻璃开关，选照片并换一张明显不同的照片。主屏幕已有小/中/大组件应显示照片。修改字体、颜色、标题、标记大小后回桌面，检查设置确实更新。连续完成/恢复 10 次，观察是否闪烁或停留旧画面；若失败，保留 App 和组件，反馈截图及发生步骤。
3. 照片选中时测试缩放/拖动/透明度。改回实色再切回照片，对比构图是否保留。相册轮换预览今天/下一天，跨日验证（更新时间由系统调度）。
4. 标记页检查“标记点按后效果”标题。分别选择保留、变淡、自定义 Emoji、细线完成圆；点击预览文字试完成，再在桌面实测。
5. 全局和单项标记分别选自定义图片（包括透明 PNG、竖图）。检查待办列表、预览、小/中/大号桌面组件、壁纸 4K PNG 都能显示。重启后确认仍保留；图片不应被强制变成圆圈。
6. 关于开启高级编辑后，小组件 → 文字：行距调至 0/标准 5/40，对比是否实际变化；选择单行/最多两行。图片、Emoji 与长中文标题不重叠、不被切掉。内容页开关未完成数量，标题页不再重复此项。
7. 标题顶部留白 0/12/24，字号 17/24/32，左右中位置及数量开关组合测试。标题每个字必须完整，不能只显示顶部/前几个字。
8. 系统亮色 + 组件底色纯黑 + 文字指定黑色，字仍应可读；再测系统深色/组件亮色、标题独立颜色、完成文字色。照片/半透明背景应有轻微护字阴影，不糊字。
9. 连续拖动照片、字号、颜色透明度、位置和行距滑条，观察跟手程度与预览响应；标准节点应吸附，精确输入不受吸附影响。每次连续拖动只需撤销一次；撤销、收起/展开、滚动无残影。
10. 主题最顶部玻璃开关单独测试：主屏幕图标默认/深色/透明三种模式各拍一张，与同屏电池组件比较。普通模式玻璃仍为实验，CI 不证明透出桌面。检查系统透明模式 Emoji/图片标记色彩是否保留。
11. 最大系统文字、显示缩放、横竖向切换、键盘弹出/关闭下检查安全区域与固定预览。壁纸缩小编辑预览后，下方工具区仍应增加高度。
12. 导出 1890×4096 与 2304×4096 PNG，检查图片标记、彩色 Emoji、文字阴影及清晰度；只有主动保存才入相册。再次覆盖安装确认数据保留。
