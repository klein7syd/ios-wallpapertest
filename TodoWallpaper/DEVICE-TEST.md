# Todo Wallpaper 0.4.4 · 真机验收

使用原账号、原 R1 Install-TodoWallpaper.cmd 直接覆盖安装；不要卸载旧 App。包内 IPA 未签名，需要 Windows iPASide/R1 签名。CI 或 Simulator 通过不代表真机通过。

1. 关于确认 0.4.4 和实际 Build。检查旧待办、排序、完成状态、Emoji、Widget 样式、壁纸照片与草稿保留。
2. 壁纸已有单项 Emoji 时，修改默认标记应统一改变画布；重新开启“使用待办的单项标记”应恢复原 Emoji。可选择单条任务编辑标记。Widget 的尺寸/颜色不应被覆盖。
3. 关于开启高级选项，在文字和标记页分别调“标记与文字间距”，左/中/右对齐都应有效。Emoji、图形、隐藏在预览与 PNG 一致。
4. 壁纸包含已完成任务时文字保持原样；无点击后划线、变淡设置。Widget 完成效果仍可调。
5. 用菜单、箭头、收起后选择工具展开设置，检查动画一致；反复滚动无漂字、残留或遮挡。系统减少动态效果开启时尊重系统偏好。
6. 壁纸“导出”高级选项调“编辑预览大小”，只改变编辑页面预览；4K 构图和像素不变，撤销可恢复。
7. 滑块靠近标准点时吸附并有系统允许的触感反馈；继续拖动可离开。精确输入可设标准点附近任意值。
8. 小组件“标题”改文字、颜色、字体、位置；关闭/开启标题或右上角数量。高级选项调大小和精确位置。检查小/中/大实际 Widget，长标题和大字不重叠。
9. 小组件“主题→照片”选择、更换、移除图片，检查主屏幕背景。撤销恢复上一张，重启后保留。编辑不自动保存相册。系统着色模式可能改变最终颜色。
10. 连续拖动一次后点一次撤销，比较响应；多次操作逐次撤销，无普通参数的读取照片遮罩/明显卡住。照片撤销单独测试，可能需要解码。重开检查草稿保存。
11. 待办页日历按钮分别读取日历日程、提醒事项；只导入勾选项，重复读取显示已导入、不重复新增、不修改系统原记录。拒绝权限显示错误；在设置允许后可重试。日程范围最多 90 天，一次最多展示 500 项。
12. 回归待办 CRUD/排序、Widget 直接完成/恢复同步、单项 Emoji、草稿/裁剪、PNG 保存/分享（19.5:9 约 1890×4096；16:9 为 2304×4096）。测试系统大字和显示缩放，最后再次覆盖安装检查数据。

导入是本地副本，不自动同步或回写 Apple。撤销只作用于当前样式编辑会话，不撤回已导出图片或待办 CRUD；重启清空历史。旧 Widget 照片暂时保留供撤销/备份使用。
