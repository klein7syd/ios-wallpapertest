# Todo Wallpaper 0.4.2 · 十一项反馈真机验收

本包是**未签名真机 IPA（含 Widget）**、原有 R1 Windows 脚本和实际检查日志／原生测试图片。未签名 IPA 不能直接安装。本轮代码、CI、Simulator 和真实 iPhone 结果分别记录。

## 覆盖安装

完整解压，USB 连接并解锁原 iPhone。iPASide 使用旧版同一 Apple Account，保持会话有效，暂停普通自动刷新并关闭窗口。运行 `Install-TodoWallpaper.cmd`，使用 R1 多扩展签名及资源检查流程覆盖安装。**不要卸载旧版。** 失败保留旧 App，只反馈可见报错，不上传账号、证书、profile、设备标识或签名成品。

关于页确认 **0.4.2** 及实际 Build，先检查旧待办、顺序、完成状态、单项 Emoji、Widget 样式、照片与壁纸草稿完整。

## 重点检查

1. 壁纸普通状态有四项系统导航。选择任一工具后，底部应只剩**左侧圆形页面入口＋当前工具胶囊**，没有完整系统 Tab Bar，也没有常驻五项工具条。胶囊菜单切换五种工具，圆形菜单切页或恢复完整导航。反复进入／退出，照片和排版不重置。
2. 壁纸标记仅作装饰，没有完成交互参数。包含已完成任务时，图标保持所选装饰样式。将壁纸样式应用到 Widget，不应覆盖 Widget 已选的完成替换策略／自定义 Emoji。
3. 在 Widget 调整图形／Emoji 大小 **8→20→24→32→48**、间距 **0→12→20→32**、描边 **0.3→3→6**、垂直偏移 **−16→16**。后半段应继续改变画面。空间不足时减少任务数，不能越界叠到其他行。
4. 爱心 ❤️ 在 8、10、12、16、19、20 点下都应完整，不能缺边。再试组合 🧑🏽‍💻、肤色 👍🏽、家人 Emoji，在预览、主屏幕和导出图检查原生颜色与完整性。
5. Widget 标记完成效果测试自定义 Emoji（用系统键盘任选列表外 Emoji）、细线完成圆、保留、变淡和原图形加勾。完成后再恢复，应回到原标记。相关参数按策略出现。
6. Widget 页面没有“全局默认”编辑选项。开启“继承壁纸标记”只继承类型／Emoji，Widget 尺寸和完成策略仍独立。关闭后修改默认标记不应改壁纸。
7. **点预览标记**：选中该任务并进入标记设置；可单独设 Emoji、恢复小组件默认。每条任务可不同，实际保存。**点预览文字**：仅试完成／恢复，真实待办状态不变；重置按钮清除试点。完成筛选可能暂时隐藏该项，重置或改成显示全部可检查效果。
8. 文字完成效果分别测试保持、仅变淡、仅划线、变淡并划线、自定义颜色。文字页和标记页的间距控件必须是同一值，互相切换应一致。
9. 开启“内容→显示行分隔线”，横线从文字起点开始，不穿过图标；上下间隔固定。大小组件及长标题检查无重叠。
10. iPhone“设置→显示与亮度→文字大小”测试小／默认／最大；再在“辅助功能→显示与文字大小→更大字体”测试较大档位。返回 App 和主屏幕大小组件，检查行数适应、标题可读、按钮仍可完成／恢复，控制区可滚动且不遮挡。壁纸成品排版保持画布比例，不应跟系统字突然变形。
11. 在系统支持的“显示与亮度→显示缩放”中切换较大显示，检查四个 Tab、编辑圆形 Dock、设置、键盘和弹窗的安全区域。模拟器缩窄检查不能代替这项真实系统设置验证。

## 回归与结果界限

反复“更多→滚动→常用→滚动”、收起／重开面板，确认文字不漂浮。再检查待办 CRUD／排序、主屏幕 Widget 直接完成／恢复和 App 同步；真实 Widget 任务按钮不应强制打开 App。

检查原草稿、照片、4K PNG 保存相册与分享：现代约 **1890×4096**，经典 **2304×4096**（旧精确比例草稿允许取整差异）。预览不增加相册图片。杀后台、重启及再次覆盖安装后，数据与单项 Emoji 仍保留。

CI 包含 macOS 生产原生回归、iOS Simulator SwiftUI 实际渲染、动态字体矩阵和截图；这些都不是你的真实 iPhone 验收。Widget 仍受系统空间、背景样式及刷新调度约束。此版本添加的文字效果／分隔线字段可读取旧设置；使用新完成策略后不要降级旧二进制回写设置。
