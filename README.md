# Todo Wallpaper
原生iOS待办、壁纸、小组件与连心；iOS17+，无第三方库。
Windows解压运行Install-TodoWallpaper.cmd，用同一账号覆盖安装，不先卸载。
本轮：连心读取失败禁止覆盖、版本与备份恢复、缺图降级、按服务商保留配置、旧请求防回写。
当前话语署名与下一次角色输入分离；删除和生成可恢复上一批；无效编辑禁止复制分享。
AI连接验证所选模型，模型列表可搜索；生成解析兼容旧单句，非法译文不丢原文，拒绝JSON残片。
公开Wiki检索增加姓名/团体筛选与8秒总预算；没有匹配就降级，不接入未授权微博/Reddit。
小组件/壁纸统一跳过缺译文，修正容量报错和摘要复制；小组件故障提示与打开连心入口。
日历支持取消和分批导入；照片同步失败可重试，草稿归档引用照片不被过期清理。
调整现有数据检查以覆盖生产批量解析、存储保护和译文筛选；无新增UI检查、无放宽旧断言。
受保护哈希仅更新Info.plist（注册连心深链）与WallpaperDraftStore（归档照片引用保护）；权限/签名不变。
密钥仅钥匙串，HTTPS/禁止重定向/响应上限保持；照片不发AI，私有资料不进共享数据。
官方目录过滤依据：https://api-docs.siliconflow.cn/docs/api/models-get；本轮未改预设型号。
未进行真机及真实付费API验证；编译和检查结果见安装包README。
默认仅Windows安装zip和15行内说明，不自动交付源码快照或运行handoff。
