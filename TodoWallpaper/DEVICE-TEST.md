# Todo Wallpaper 0.4.1 · 原生 UI 反馈修订验收

包内为**未签名真机 IPA**（含 Widget）、原有 R1 Windows 脚本、真实编译日志及检查结果。未签名 IPA 不能直接安装。保持三个安装标识与原数据不变，**不要卸载旧 App**。

## Windows 覆盖安装

1. 完整解压 ZIP。USB 连接并解锁、信任原 iPhone。
2. iPASide 使用旧版同一 Apple Account，保持会话有效；暂停普通自动刷新并关闭窗口。
3. 运行 `Install-TodoWallpaper.cmd`，必要时指定 iPASide 路径。继续使用 R1 分别签名 App/Widget、验证资源完整性后覆盖安装，勿使用移除扩展的普通单 App 模式。
4. 遇到错误保留旧 App，仅反馈可见报错；不上传账号、证书、profile、设备标识或签名成品。
5. 关于页确认 **0.4.1** 和包内实际 Build。确认旧待办、顺序、完成状态、单项 Emoji、全局/Widget 样式、草稿和背景照片保留。

## 七项反馈重点复测

1. **四个一级页**：待办 / 壁纸 / 小组件 / 关于逐个切换。小组件页直接可用；关于和壁纸不再重复推入另一个小组件设置页面。
2. **导航与 Dock**：进入壁纸后先看到系统四项导航。点击背景/面板/文字/标记/导出，系统 Tab Bar 应收起，底部只留左侧圆形页面菜单和工具。五个工具直接切换，当前项突出。收起参数后点当前工具可重开。圆形菜单分别前往其他三个页面，再返回壁纸；选择“显示完整导航”应恢复四项系统栏。不能重叠两套主导航或无法退出。
3. **动态参数**：Emoji 只显示 Emoji 大小/间距及更多页的对齐/完成效果；空心圆、细线圆、方框有描边而无填充；实心优先填充，边框在更多；带边框圆保留两种颜色；无标记没有无用 Slider。开启颜色跟随文字后隐藏独立颜色。关闭自定义位置隐藏 X/Y；自动高度隐藏手动高度；无照片隐藏裁剪。切回原选项检查原数值仍在。
4. **真实样例**：在壁纸、小组件和待办单项编辑中选择圆圈/方框/Emoji 卡片，检查实际图形与选中状态；用系统 Emoji 键盘输入快捷列表之外的 Emoji，试组合和肤色标记，预览及任务数据应正常保留。
5. **圆角与边界**：检查外面板、内部工具和选项卡的连续圆角层级。上下滚动时，文字、Slider、说明不得绘制到面板外、画布上或 Home Indicator 下。
6. **固定 Widget 预览**：切小/中/大，只有下方设置滚动。预览始终可见，比例保持，小屏也有操作空间。切主题/字号/标记/密度，观察真实待办即时变化；预览任务不会实际完成，真正主屏幕 Widget 仍应可完成/恢复。背景不透明度 0–1 只调整自定义底色；网格仅用于 App 示意，不导出、不进入 Widget。
7. **文字漂浮复现**：壁纸“标记”进入更多，滚到底部，返回常用，再继续上下滚动；连续切换几种标记，再收起整个参数、重开，重复至少 10 次。面板/文字/背景也做同样操作。再在小组件四类设置中重复“更多→滚动→返回常用→滚动”。旧 DisclosureGroup 已替换为分离的常用/更多页，检查没有漂浮、残留、重叠或失去当前设置。

## 回归与安全区域

- 在精确数值或 Emoji 输入时打开键盘，用“完成”收起；再开关系统取色器、照片选择器、分享页和全屏预览。确认 Dock、参数与画布恢复正常，没有文字漂浮或遮挡。
- 竖屏、横屏和放大字体下检查安全区域与触控；屏幕较小或键盘弹出时，画布/固定预览会缩小，设置仍应可滚动。如有问题反馈机型、系统版本和复现步骤。
- 待办新增/编辑/删除/排序/完成/恢复；主屏幕小、中、大 Widget 直接完成/恢复，确认不强制开 App；返回 App 同步正确。
- 已选照片与草稿保持。拖动背景/面板、双指缩放、字重、颜色、单项/全局标记正常。导出现代画布 **1890×4096**、经典 **2304×4096** PNG（旧精确比例草稿可能因取整略有差异），在照片信息核对实际尺寸；保存与系统分享正常，预览不增加相册图片。
- 杀后台/重启后确认所有数据，再用同账号脚本覆盖安装一次。不要卸载。

## 结果界限

CI 执行原生编译、生产持久化/迁移/4K/字体/Emoji 图像检查、可执行导航状态检查及源码布局约束。**没有自动操作真实 iPhone，不能据此宣布滚动、键盘、安全区域、签名或安装通过。** 本轮文字漂浮修复需以上真机复测确认。

Widget 实际背景、着色、透明风格和刷新调度由 iOS 管理；App 不承诺任意主屏幕照片透出。固定预览复用实际 Widget 内容，但参考尺寸、宿主边距和系统样式仍可能不同。实时 GPU 模糊和导出 Core Image 有细微差别，高清导出仍按目标像素重新绘制 SDR PNG。
