# Todo Wallpaper 0.5.0 · 真机验收

同一账号用原 iPASide/R1 Install-TodoWallpaper.cmd 直接覆盖安装，不卸载。包内 IPA 未签名，CI 不代表安装/真机通过。

1. 关于核对版本与 Build。检查旧任务 ID 对应的标题/排序/状态/Emoji、壁纸照片与草稿、Widget 样式保留。
2. 壁纸背景照片拖动、双指缩放，面板拖动：连续操作比较流畅程度，松手后一次撤销应回到手势开始前。拖动中不应出现读照片或制作整图遮罩。真实帧率以 iPhone 为准。
3. 关于开启高级选项，在壁纸导出中调小“编辑预览大小”：设置区应向上扩大，减少无用空白；恢复标准值回到原布局。PNG 比例、构图、像素不变。
4. 小组件主题→照片，开启“手指调整照片”。直接拖动/双指缩放，调整不透明度；关闭调整后预览文字与标记恢复点击操作。小/中/大组件与桌面实际裁剪一致，无拉伸。重启、覆盖安装后保留。
5. 手机保持浅色，Widget 分别选择深色/亮色/跟随系统，检查背景与白/黑字可读；再用系统深色重复。自定义文字色应保留。
6. 小组件内容开关“显示左下角说明”；文字页应显示“文字点按后效果”标签，原完成效果仍可选，实际 Widget 能完成/恢复并同步。
7. 新建/编辑待办：日期关闭时为原来的无日期任务；开启选日期，再开启时间。保存、重开、改标题/Emoji、Widget 完成/恢复后日期保留。关闭日期再保存应移除日期。旧任务不自动加日期。
8. 新建待办中的“从日历/提醒事项导入”可打开原导入流程，系统权限拒绝/允许均正确处理；只导入勾选项，不回写系统记录。
9. 主题→系统材质背景（实验）：在桌面图标默认/深色模式分别比较关闭/开启；再在系统透明/着色模式检查已验证的透明能力保留。请反馈是否有真实背景采样/玻璃、是否被系统压成底色。App 预览不能证明桌面模式支持。
10. 照片背景→选择相册，每天换一张，允许完整照片权限，选择有多张照片的相册。准备完成后点“预览下一张”比较。设置不同裁剪/透明度、重启后检查；保持 App 关闭跨日期观察桌面 Widget。系统可能延迟刷新。
11. 关闭/重开每日轮换；相册变动后重新选择同步。有限/拒绝照片权限时有说明；单张 PhotosPicker 仍可使用。最多使用相册最近 60 张，照片保存在本机；旧文件留作撤销/备份。
12. 回归四个一级导航、数据备份恢复、Emoji、真实 Widget Intent、4K PNG 保存/分享（约1890×4096、2304×4096）和再次覆盖安装。系统大文字/显示缩放下控件仍可滚动，预览不遮挡操作。

日期目前用于显示和管理，不发送通知。日历/提醒事项导入为独立本地副本。每日换图使用系统时间线，不能承诺零点秒级刷新。系统材质是公开 API 的实验请求，默认/深色下是否与电池组件一致须真机确认。
