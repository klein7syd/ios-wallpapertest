# Todo Wallpaper 0.1.0 · 阶段 B 真机测试

这是正式 App 的首个本机待办版本，Bundle ID 为 `org.todowallpaper.app`。它与“原生安装测试”并存，两者的数据互不迁移或覆盖。此 IPA 尚未签名。

## Windows 安装

1. 将此 ZIP 完整解压，打开 iPASide，使用你此前安装成功的 Apple Account。
2. 连接、解锁 iPhone，将 `TodoWallpaper-unsigned.ipa` 拖入 iPASide，按此前成功的普通 Sideload 流程签名安装。
3. 本阶段只有主 App，没有扩展，使用 iPASide 普通流程即可。不要使用固定识别测试 Bundle ID 的 `Install-WidgetProbe.cmd`。
4. 手机打开 **Todo Wallpaper**。在“关于”页核对版本 **0.1.0**、本包构建号及实际安装标识。原“原生安装测试”App 应仍在。
5. 后续更新沿用同一账号和实际安装标识直接覆盖。不要先卸载。

## 验收清单

- [ ] 新增三条不同待办，包含中文、emoji 和较长文字；空白内容不能保存。
- [ ] 点文字编辑，保存后正确更新；点取消保持原内容。
- [ ] 点圆圈完成，再点恢复；其他事项不变。
- [ ] 点左上角“编辑”，用拖动手柄调整顺序，退出编辑。
- [ ] 左滑删除其中一条；其他任务和顺序保持正确。
- [ ] 划掉后台再打开，内容、顺序、完成状态和删除结果均保留。
- [ ] 重启 iPhone 后再打开，数据仍在。
- [ ] 使用同一包覆盖安装一次，原待办保持。这个测试只能验证同构建覆盖；后续更高构建仍需单独实测。
- [ ] 切换浅色/深色，检查系统底栏、编辑弹窗及键盘是否可正常使用。

请反馈安装是否成功，以及新增/编辑/删除/排序/完成/重开保存的结果。代码编译与自动化检查通过不表示上述设备交互已通过。

## 本轮范围与限制

仅待办管理、本机持久化和 SwiftUI 原生底部导航。正式 App 尚未加入 Widget、App Intents、App Groups、壁纸、AI 或个性化模块；原 R1 测试工程的这些能力不受影响。

数据有 schema 版本；保存采用文件锁和原子写入，并保留上一次成功保存的备份。遇到损坏或更高版本文件时显示读取失败并保留文件，不会自动重置。当前尚未提供备份导入/手动恢复界面。

已知待实测项：签名安装、键盘和排序交互、设备重启、覆盖安装保留，以及无障碍/大字号布局。图标与视觉细节留待后续阶段。
