# 0.6.1 — iPhone 验收（本轮尚未真机验证）

IPA 未签名。完整解压 Windows ZIP，用原来 iPASide 的同一 Apple 账号和根目录 Install-TodoWallpaper.cmd 覆盖安装，不先卸载旧 App。实际构建号以关于页与包内 status.json 为准；安装后先检查原待办、顺序、完成状态、标记、日期、照片和草稿保留。

1. 小组件分别选黑字、白字、粉字，在明暗照片对比蒙层色与阴影色；白蒙层在暗图更强、亮图更弱。日期、标题、摘要与分隔线清晰。
2. 形状/Emoji/自定义图片标记都有同文字的阴影；真实着色模式不加效果。当前只注册主屏小/中/大规格；共享锁屏family门禁有模拟器检查，未新增锁屏组件。
3. 放大、拖动、改透明度及明暗主题，结束后观察“自动”数值更新与大图流畅度；400ms是去抖，实际耗时受IO/系统调度影响。三个锚点、负边距与不同尺寸检查贴边效果。
4. 相册预览今天/下一张，调整crop对所有图片生效；跨日检查系统刷新，回到App可补算缺失分析。
5. 真正iCloud照片读取及取消：少量失败应提示跳过数，全部/过半失败或取消应撤回本次导入，不能影响先前相册。恰好半数失败允许提交。失败阈值和文件事务已有原生回归，网络体验待此项验收。
6. 重复换相册、移除照片后观察可回收旧图；撤销与备份仍引用的图会保留，十分钟新图、导入中和加载失败不删，不以“尚未删除”直接判失败。
7. 取鲜艳颜色应立即生效且撤销可用；存储损坏或未来版本保护错误不应被普通调色隐藏。
8. 日期/带时间日期与原版文字一致；切地区、日历和时区后再看。双指一方取消、另一方正常结束应保留调整；全部取消回到原值。连续微调可一次撤销，步进仍一个导出像素；录屏确认是否存在视觉跳变。
9. 原生与编译证据见包内Evidence。另测试大字体、显示缩放、键盘、安全区、慢拖/快滑、收起/展开与撤销；这些模拟器或CPU回调结果不代表真机120Hz验收。

导出1890×4096与其他合法尺寸PNG，检查方向、零透明底色、Emoji/图片标记、清晰度与无旧文字阴影。静态壁纸无旧完成态视觉区分是有意设计，圆环不可点击；只有主动保存才入相册。再次覆盖安装确认保留数据；免费签名过期后沿原流程重签。
