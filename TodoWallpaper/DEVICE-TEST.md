# Todo Wallpaper 0.3.0 · D1 + D2

此包包含未签名的真机 ARM64 App 与 Widget，以及沿用 R1 的 Windows 多扩展签名安装脚本。未签名 IPA 不能直接安装。关于页显示实际构建号。请勿卸载 0.2.0 / 1002。

## Windows 覆盖安装

1. 完整解压下载的 ZIP，不要只取 IPA。USB 连接、解锁并信任现有 iPhone。
2. iPASide 使用安装 0.2.0 时的同一免费 Apple Account，确认会话可用。暂时暂停普通自动刷新并关闭 iPASide 窗口，避免刷新旧包或移除扩展。
3. 双击 `Install-TodoWallpaper.cmd`，必要时输入 iPASide 安装目录。脚本使用该安装中的引擎完成主 App 与 Widget 的独立签名、资源完整性检查及覆盖安装。
4. 保留同一安装身份。正式源标识仍为 `org.todowallpaper.app`、`org.todowallpaper.app.widget`、`group.org.todowallpaper.app`；脚本继续复用已安装的账号后缀及共享组映射。不要用测试工程的 Bundle ID。
5. 如果报错，保留手机 App，提供可见错误；不要上传账号、证书、profile 或已签名 IPA。CI 成功不代表本地签名/安装成功。

## 优先回归现有能力

- 查看关于页为 0.3.0，记录构建号；原待办的内容、顺序、完成状态均保留。
- 新增、编辑、排序、完成与恢复各一项；杀后台后数据仍在。
- 已有小中大小组件仍可显示；杀后台后点击任务直接完成，打开 App 同步。

## 壁纸验收

1. 打开原生“壁纸”底部页面。无需选照片即可看到真实待办；没有待办显示空状态。面板默认水平和垂直居中。
2. 在“背景”通过 PhotosPicker 选择竖图、横图、带旋转方向的 HEIC/JPEG。双指缩放、拖动和滑杆均可调整，裁剪不应露白。取消选择应保留现有背景。
3. 切换“面板”：检查宽度、自动/固定高度、自定义水平/垂直中心、圆角、底色透明度、模糊、边框、高光与内边距。连续滑动或点击数值精细输入，预览应更新。
4. 切换“文字”：未完成/全部、数量、系统/衬线/等宽、字号、字重、颜色及透明度、对齐、行距、事项间距、每项行数、完成样式。使用长中文和 emoji 标题检查换行，超出显示省略号或“另有 N 项”。
5. 切换“导出”：先用默认 iPhone 13 Pro **1170 × 2532**，再换其他预设及自定义 1200 × 1200。相对位置应保持，面板不应超出画布。无效尺寸应提示且保留之前的尺寸。
6. 点击左上角隐藏控制区域查看完整预览。右上角“恢复排版默认值”需确认，保留有效背景与输出分辨率，待办不变。
7. 编辑过程中查看相册，确认没有自动新增图片。点击“保存到相册”才添加；相册权限拒绝时应明确提示，仍可使用“系统分享”保存到文件。
8. 导出 PNG 后在照片信息或“文件”中核对 **1170 × 2532 像素**；检查文字锐度、照片方向、裁剪、面板位置及换行与预览基本一致。可放大成品检查，不能只看编辑页。
9. 修改主 App 待办后回到壁纸，确认使用新内容；此前保存的壁纸保持静态，不会自动变成新内容。
10. 杀后台、重开 App，确认背景和壁纸参数仍在。清理“导出缓存”不应删除背景、待办、已存相册的成品。再次用同账号脚本覆盖安装，原待办和草稿仍在。

## 已知边界

- 壁纸是静态 PNG，请在系统照片/设置手动设置，不支持后台静默更换。
- 壁纸玻璃使用 Core Image 背景模糊、黑/白中性底色及高光；与实时预览共用绘制代码，但不是系统实时 Liquid Glass 的离屏复制，不能承诺跨尺寸像素级一致。
- 图片在本机处理，无上传接口。PhotosPicker 可能由系统下载用户选中的 iCloud 照片。
- 默认单份本地草稿；仅字体预设，不含自定义字体文件导入。壁纸使用明确字号，不随动态字体改变，以保持导出排版。
- 照片原文件保留；解码长边最多 6144，缩放 1–4 倍。原图不足或过度放大时提示清晰度风险，不能制造原图没有的细节。PNG 为 SDR sRGB，当前不保留 HDR/动态照片/原图定位信息。
- 自定义每边 480–4096，总像素上限 1200 万。面板有最小内容高度及边界约束；极端窄面板/大字会减少显示项数。
- 预览会合并快速连续操作，复杂图片可能稍有延迟。导出期间会显示进度并暂时禁用参数，避免同时修改与重复渲染。
- 未使用网页、AI、翻译或自动换壁纸功能。D3 + D4 未开发。

代码与 CI 检查结果另见 status.json、build.log、repository-checks.log、render-checks.log 和 render-checks/。本版 Windows 签名、覆盖安装、相册权限、触控及真机成品效果仍等待用户反馈。
