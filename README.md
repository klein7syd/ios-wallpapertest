# Todo Wallpaper
原生 iOS 待办、壁纸、小组件与连心；最低 iOS 17。
本轮 UI：连心按角色、创作、话语、外观重排，常用生成操作提前。
语言与翻译可展开，参考资料收进折叠区，角色字段保留固定标签。
每句话语独立圆角卡片；壁纸和小组件调整按钮统一，底图操作紧邻预览。
连接状态整行可点；AI 设置的下一步固定底部，键盘打开时让出输入空间。
待办列表采用分组样式，完成按钮触控区域扩大到44pt，新增按钮圆角18。
保持现有数据、生成、安全规则及共享渲染；不修改受保护源码哈希。
未新增UI检查或放宽原检查；本轮编译结果见安装包README。
Windows解压运行Install-TodoWallpaper.cmd，用原账号覆盖安装，不先卸载。
