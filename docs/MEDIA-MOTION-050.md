# 0.5.0 — photo motion, dates and daily rotation

Final test candidate 0.5.0 / 1025, code `78228c653a0608d6d3cacac14dc0d3760f94cdfe`. [Actions 40465212518](https://github.com/klein7syd/ios-wallpapertest/actions/runs/40465212518) passed. Windows signing, install, iPhone gesture frame rate, PhotoKit permissions and Home Screen material remain unverified.

- Wallpaper uses a retained UIKit/Core Animation layer tree. Pan/pinch move existing photo/blur textures and panel layers without publishing model changes or saving on each frame. One finished gesture commits one undo state. A small blurred source texture (maximum 768px edge) is prepared off the main actor only after source/blur/zoom/ratio settles. Full target-pixel wallpaper composition remains in exact preview/export. Live blur while zooming is approximate until settled.
- Widget photos share normalized zoom/pan geometry between the native gesture editor and Widget background. Alpha blends the photo with its theme background; it does not grant arbitrary access to the Home Screen wallpaper. Crop applies to all photos in a rotation, and each Widget size uses aspect fill without stretching.
- Explicit light/dark Widget color resolves its own solid system base and foreground, rather than depending on the phone's color scheme. Accented/clear rendering still delegates foreground and container removal to WidgetKit.
- Footer has a switch and actually releases row space. Text completion has a visible 文字点按后效果 label.
- Wallpaper preview-size preference now reallocates its freed height to the inspector instead of leaving blank space. No export coordinates change.
- Optional task schedule uses calendar components, date with optional time. Old JSON/IDs/order/completion/markers remain compatible. Existing title/marker/Intent operations preserve schedule; the task editor can explicitly clear it. Dates appear in App and Widget. Create-task sheet can open the existing Calendar/Reminders import. New imports keep date in structured metadata; old imported titles are not rewritten. This adds display/management metadata, no notifications or calendar back-write.
- PhotoKit album selection explicitly requests full library access (limited access can still use the single-photo picker). Up to 60 most recent still photos are resized into local App Group files. No photo is uploaded or saved back to the album. App Groups store only generated local names for rotation; Photos asset/album identifiers are not in shared appearance or public source.
- Eight Widget timeline entries cover now and seven following local midnights, handling calendar days/DST rather than 24-hour arithmetic. The system controls actual delivery timing. Re-select the album to update its cached contents after changes; the extension does not silently download/re-read a private Photos library. Disabling rotation returns to the saved single image. Old references are retained for undo/backups.
- Experimental system material toggle requests public ultraThinMaterial in the Widget container. Apple documents system glass for clear/tinted contexts, not a guarantee of the first-party Batteries appearance in default/dark icon modes. No private API, wallpaper screenshot stitching or claim of verified Home Screen glass is used. Real default/dark and clear modes must be tested separately.

IDs and R1 installer remain unchanged. Intent and App Group migration remain byte-identical. Reviewed protected changes: optional TodoItem.schedule and repository validation/save wrapper, App purpose string for album access, TodoStore date-save wrapper. Existing lock/backup/version barriers are kept.

Verification: local source guards; native Core crop/layout/DST/legacy/data tests; iOS Simulator production CA layer-update callbacks with zero per-frame commits, photo pan/alpha pixel output, dark-Widget/light-system contrast, existing glyph/export/undo regression. Callback timing does not establish real iPhone FPS. PhotoKit access/album copying, real time passage, default-mode material and install/signing require iPhone feedback.

Primary references: [Apple WidgetKit foundations](https://developer.apple.com/videos/play/wwdc2026/277/), [Liquid Glass and accented rendering](https://developer.apple.com/documentation/widgetkit/optimizing-your-widget-for-accented-rendering-mode-and-liquid-glass), [keeping widgets up to date](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date), [PhotoKit access](https://developer.apple.com/documentation/photokit/delivering-an-enhanced-privacy-experience-in-your-photos-app).
